## Краткое описание задания

Дано однофайловое веб‑приложение‑кликер на чистом HTML/CSS/JavaScript.  
После очень большого количества кликов обещают показать флаг, но честно накликать столько невозможно, поэтому задачу нужно решать через анализ и модификацию JS в браузере.

Это простой веб/reversing‑таск про чтение inline‑кода, base64 и инверсию строки.

## Как решить

- **Способ 1: через base64 и инверсию строки**
  1. Открыть выданный `index.html` в браузере и посмотреть исходный код (View Source) или через DevTools.  
  2. Изучить функцию проверки количества кликов и вывода флага

- **Способ 2: накрутить клики через консоль**
  1. Открыть `index.html` в браузере.  
  2. Открыть DevTools → вкладка Console.  
  3. Установить большое значение счётчика кликов:
     ```js
     window.state.clicks = 999999;
     ```
  4. Нажать кнопку «Клик!» ещё раз.  
     Встроенная проверка вида `if (window.state.clicks >= ... ) { ... }` сработает, и клиентский JS сам выполнит показ флага.
