# Writeup: It's a base

## Анализ задания
Нам дан файл `message.txt`, содержащий длинную строку из шестнадцатеричных символов (0-9, a-f). Скрипта шифрования у нас нет, но название задания "It's a base" (игра слов: "It's a base" / "It's about base") намекает на использование кодировок семейства Base.

Попробуем раскрутить цепочку "луковичного" шифрования, основываясь на внешнем виде данных.

### Шаг 1: Hex
Строка состоит только из цифр и букв `a-f`. Очевидно, это Hex-кодировка.
Декодируем Hex -> Bytes.
Получаем набор байтов, который выглядит как ASCII-текст, но странный.

### Шаг 2: Base85
Если посмотреть на полученные байты, можно увидеть характерные символы для Base85 (например, много символов из расширенного ASCII диапазона, используемых в b85encode, или просто попробовать популярные кодировки).
Декодируем Base85 -> Bytes.

### Шаг 3: Base32
Результат предыдущего шага напоминает Base32 (буквы A-Z и цифры 2-7).
Декодируем Base32 -> Bytes.

### Шаг 4: Binary String
После декодирования Base32 мы получаем строку, состоящую только из `0` и `1`. Это бинарное представление данных. Но это не сами байты, а строка символов.
Нужно разбить эту строку на группы по 8 бит и преобразовать каждую группу в символ (байт).

### Шаг 5: Base64
Полученные байты выглядят как классический Base64 (A-Z, a-z, 0-9, +, /).
Декодируем Base64 -> Flag.

## Решение
Чтобы получить флаг, нужно выполнить декодирование в обратном порядке. Поскольку у нас нет исходного кода, мы подбираем кодировки методом "тыка" и анализа вывода на каждом шаге.

Для решения можно использовать готовый рецепт cyberchef
```
From_Hex('Auto')
From_Base85('0-9A-Za-z!#$%&()*+\\-;<=>?@^_`{|}~',false,'')
From_Base32('A-Z2-7=',true)
From_Binary('Space',8)
From_Base64('A-Za-z0-9+/=',true,false)
```
