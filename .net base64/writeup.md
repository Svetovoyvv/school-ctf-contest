# Writeup: .NET Base64 Password

## Описание задачи
Вам дан исполняемый файл `PasswordChecker.exe`, который запрашивает пароль. Известно, что приложение написано на .NET, а пароль проверяется внутри.

## Решение

### Шаг 1: Анализ файла
Запускаем приложение и видим запрос пароля. Пробуем ввести случайные данные — получаем "Пароль неверный!".
Так как это `.exe` файл, написанный на .NET (как указано в задании или определено с помощью инструментов типа `file` или `Detect It Easy`), можно попробовать использовать декомпиляторы (например, `dnSpy` или `ILSpy`).

Однако, перед декомпиляцией всегда полезно проверить содержимое файла простыми инструментами, например `strings` или `grep`, так как важные данные могут храниться в открытом виде.

### Шаг 2: Поиск строк
Попробуем найти строки, содержащие слово "Password" или "Flag" внутри бинарного файла, так как это стандартные форматы для таких задач.

Используем команду `grep` с флагом `-a` (для обработки бинарного файла как текста):

```bash
grep -a "Password is" PasswordChecker.exe
```

Или, если вы на Windows, можно открыть файл в Notepad++ (будет много мусора, но поиск работает) или использовать `strings` из набора Sysinternals:

```cmd
strings PasswordChecker.exe | findstr "Password is"
```

### Шаг 3: Получение флага
Команда вернет строку вида:
`Password is <BASE64_STRING>`

Например:
`Password is Y3Rme2Jhc2U2NF9uMHRfc2VjdXIzfQ==`

Это и есть закодированный пароль/флаг. Само приложение при вводе пароля кодирует ваш ввод в Base64 и сравнивает с этой строкой.

### Шаг 4: Декодирование

**Linux / macOS:**
```bash
echo "Y3Rme2Jhc2U2NF9uMHRfc2VjdXIzfQ==" | base64 -d
```

**Windows (PowerShell):**
```powershell
[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String("Y3Rme2Jhc2U2NF9uMHRfc2VjdXIzfQ=="))
```

Результат: `ctf{base64_n0t_secur3}`

Это и есть правильный пароль.
