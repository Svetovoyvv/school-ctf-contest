# Oh no memory limit

## Описание
Наш дизайнер пытался отправить секретный флаг, но пожаловался, что "картинка занимает слишком много места" и скрипт сохранения "упал с ошибкой памяти", обрезав самое важное.

Файл действительно выглядит обрезанным, но размер файла кажется подозрительно большим для такой маленькой картинки. Может быть, данные всё еще там?
