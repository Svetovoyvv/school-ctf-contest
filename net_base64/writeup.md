# Writeup: .NET Base64 Password

## Описание задачи
Вам дан исполняемый файл `PasswordChecker.exe`, который запрашивает пароль. Известно, что приложение написано на .NET, а пароль проверяется внутри.

## Решение

### Шаг 1: Анализ файла
Запускаем приложение и видим запрос пароля. Пробуем ввести случайные данные — получаем "Пароль неверный!".
Так как это `.exe` файл, написанный на .NET (как указано в задании или определено с помощью инструментов типа `file` или `Detect It Easy`), нужно использовать декомпилятор.

## Решение: Декомпиляция в dnSpy

### Шаг 1: Открытие в dnSpy
Открываем `PasswordChecker.exe` в dnSpy (или ILSpy). Находим класс `Program` и смотрим на код:

- Видим метод `Main`, который считывает пароль от пользователя
- Видим метод `EncodeToBase64`, который кодирует введенный пароль в Base64
- Видим переменную `storedFlag`, которая содержит строку в формате "Password is {BASE64}"
- Алгоритм: программа кодирует введенный пароль в Base64 и сравнивает с захардкоженной строкой

### Шаг 2: Извлечение закодированного пароля
Из кода видим строку типа `"Password is Y3Rme2Jhc2U2NF9uMHRfc2VjdXIzfQ=="`. Извлекаем Base64 часть.

### Шаг 3: Декодирование Base64
Декодируем извлеченную Base64 строку и получаем флаг.

**Linux / macOS:**
```bash
echo "Y3Rme2Jhc2U2NF9uMHRfc2VjdXIzfQ==" | base64 -d
```

**Windows (PowerShell):**
```powershell
[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String("Y3Rme2Jhc2U2NF9uMHRfc2VjdXIzfQ=="))
```

Результат: `ctf{base64_n0t_secur3}`

Это и есть правильный пароль.
