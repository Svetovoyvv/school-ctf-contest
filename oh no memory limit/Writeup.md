# Writeup: Oh no memory limit

## Анализ
Участник получает файл `secret.png.clip.png`. При открытии видно текст, но изображение обрезано снизу, где должен быть флаг.
Суть таска основана на том, что данные изображения (chunk `IDAT`) сохраняются полностью, но заголовок (`IHDR`) указывает меньшую высоту. Визуально картинка обрезана, но пиксельные данные не удалены.

## Решение

### Способ 1: Использование оригинальной утилиты (Intended)
Можно найти утилиту [pngresize](https://github.com/Svetovoyvv/pngresize), которая использовалась для создания таска. Она позволяет изменять размеры холста PNG, корректно пересчитывая CRC.

1. Клонируем утилиту:
   ```bash
   git clone https://github.com/Svetovoyvv/pngresize
   ```
2. Восстанавливаем высоту (исходная высота была ~400):
   ```bash
   python pngresize/pngresize.py secret.png.clip.png --height 400 -o solved.png
   ```
3. Открываем `solved.png` и читаем флаг.

### Способ 2: Hex Editor
1. Открываем файл в Hex-редакторе (HxD, 010 Editor, Bless и т.д.).
2. Ищем чанк `IHDR` (сразу после сигнатуры PNG `89 50 4E 47 ...`).
3. Структура `IHDR`: `Width (4 bytes) | Height (4 bytes) | ...`
4. Высота установлена в `00 00 00 78` (120 px).
5. Меняем высоту на `00 00 01 90` (400 px) или больше.
6. Сохраняем файл.
   *Примечание:* CRC чанка `IHDR` станет неверной. Большинство браузеров откроют картинку и так, но строгие просмотрщики могут выдать ошибку. Для исправления CRC можно использовать `pngcheck` или функции редактора.
