## zero_one

Команда SOC зафиксировала аномальную сетевую активность: одна из систем защиты сообщила о передаче зашифрованных данных по засекреченному каналу. В ходе расследования удалось перехватить аудиофайл, содержащий нужную информацию.

Ваша задача — извлечь скрытые данные из предоставленного звука. Полученный флаг необходимо обернуть в соответствии с форматом, заданным организаторами. Все латинские буквы должны быть в верхнем регистре.
