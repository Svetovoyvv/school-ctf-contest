# Прохождение: Перехват трафика

## Что нужно сделать

Нам дан файл `traffic.pcap` - это дамп сетевого трафика. В нём куча разных запросов (мусор), но где-то спрятаны:
1. **Пароль от архива** - передан через HTTP
2. **Сам архив** - передан через FTP
3. **Флаг** - внутри архива

Задача: найти пароль, извлечь архив, распаковать его.

---

## Решение в Wireshark

### Шаг 1: Найти пароль

1. Откройте файл `traffic.pcap` в программе **Wireshark**

2. В верхней части экрана есть строка для фильтров. Введите туда:
   ```
   http.request.method == "POST"
   ```
   
3. Вы увидите много HTTP запросов. Большинство из них - мусор (к портам 9000, 9001, 9002, 9003)

4. Найдите запрос к **порту 8080** (смотрите в столбец Info или Destination Port)

5. Кликните на этот пакет **правой кнопкой** → **Follow** → **HTTP Stream**

6. В открывшемся окне вы увидите запрос вида:
   ```
   POST /submit_password HTTP/1.1
   ...
   
   archive_password=a1b2c3d4e5f6...
   ```

7. **Скопируйте пароль** (всё после `archive_password=`) - это длинная строка из букв и цифр

---

### Шаг 2: Извлечь архив

1. Закройте окно HTTP Stream и сбросьте фильтр (крестик рядом со строкой фильтра)

2. Введите новый фильтр:
   ```
   ftp-data
   ```

3. Вы увидите пакеты с данными FTP. Найдите тот, где передаётся файл (обычно это самый большой пакет)

4. Кликните на пакет **правой кнопкой** → **Follow** → **TCP Stream**

5. В открывшемся окне:
   - В выпадающем списке **"Show data as"** выберите **"Raw"**
   - Нажмите кнопку **"Save as"**
   - Сохраните файл как `secret.zip`

---

### Шаг 3: Распаковать архив

1. У вас теперь есть:
   - Файл `secret.zip`
   - Пароль (который вы скопировали)

2. Откройте архив любым архиватором (WinRAR, 7-Zip, и т.д.)

3. Введите пароль, когда программа попросит

4. Внутри будет файл `flag.txt` с флагом

5. Откройте `flag.txt` и скопируйте флаг!
