# Прохождение: Кто ты?

## Анализ

1. Нам дан файл с именем `confidential`.
2. Попытка распаковки завершается ошибкой:
   ```bash
   unzip confidential
   # Archive:  confidential
   #   End-of-central-directory signature not found.  Either this file is not
   #   a zipfile, or it constitutes one disk of a multi-part archive.
   ```
3. Проверка командой `file` говорит просто "data", что не помогает.
4. Открытие файла в hex-редакторе (`xxd` или аналог) показывает первые байты:
   ```
   00000000: 5748 4f04 1400 0000 0800 ... WHO.....
   ```
5. В ASCII представлении видно "WHO".
6. Стандартная сигнатура ZIP файла (магические байты) начинается с `PK` (`50 4B 03 04`).
7. Описание задания намекает на "WHO".

## Решение

### Linux / macOS

1. Откройте файл в hex-редакторе.
2. Замените первые 3 байта `57 48 4F` (`WHO`) на `50 4B 03` (`PK\x03`). 4-й байт обычно `04`, что соответствует стандартной сигнатуре локального заголовка файла `50 4B 03 04`.
   - Было: `57 48 4F 04`
   - Стало: `50 4B 03 04`
3. Сохраните файл.
4. Распакуйте архив:
   ```bash
   unzip confidential
   ```
5. Прочитайте флаг из `flag.txt`.

### Windows

1. Скачайте и установите любой Hex-редактор (например, **HxD**).
2. Откройте файл `confidential` в HxD.
3. Вы увидите, что первые байты файла — `57 48 4F` (текст "WHO" в правой колонке).
4. Нажмите на первый байт `57` и введите `50`, затем `4B` вместо `48`, и `03` вместо `4F`.
   - Должно получиться начало: `50 4B 03 04` (текст "PK..").
5. Сохраните изменения (Ctrl+S).
6. Добавьте расширение `.zip` к имени файла (переименуйте в `confidential.zip`).
7. Теперь файл можно открыть как обычный архив и извлечь `flag.txt`.
