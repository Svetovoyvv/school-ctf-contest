## image_history — разбор

Флаг был спрятан по частям в полях метаданных изображения:

- Название (Title)
- Описание (ImageDescription)
- Авторы (Artist)
- Комментарий (UserComment)
- Авторские права (Copyright)
- Камера (Model)

Шаги решения:

1. Открываем `history.jpg` в любом просмотрщике метаданных (exiftool, exifGUI, онлайн-сервисы).
2. Смотрим указанные поля и выписываем содержимое каждого — там лежат кусочки флага.
3. Склеиваем части в правильном порядке (Title → Description → Author → Comment → Copyright → Model).
